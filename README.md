# Візуалізація роботи блокчейну

Курсова робота. Ядро на **Rust**, інтерфейс відображає **Chromium** у режимі вікна застосунку (`--app`). Інтерфейс написано на HTML, CSS і JavaScript.

## Запуск

Потрібні Rust і Chromium (на Arch Linux: `sudo pacman -S chromium`).

```bash
cargo run --release
```

Програма запускає локальний сервер на `127.0.0.1` і відкриває вікно Chromium. Коли вікно закривається, програма завершується. Ланцюг зберігається у файл `chain.json` у поточній теці і відновлюється при наступному запуску.

Тести:

```bash
cargo test
```

## Що можна робити

- **Майнити** новий блок: ввести дані і натиснути «Майнити». Програма перебирає nonce, доки SHA-256 хеш не почнеться з потрібної кількості нулів.
- **Складність** (1–5) діє на нові та перемайнені блоки.
- **Вибрати блок** кліком: у панелі з'являться час, nonce, хеш, попередній хеш і дані.
- **Підробити**: змінити дані без перерахунку хешу. Блок стає червоним, наступні тьмяними.
- **Перемайнити** блок або «Перемайнити до кінця», щоб відновити ланцюг.
- **Покрокове пояснення** з'являється після «Майнити» і для будь-якого блоку кнопкою «Як створено цей блок». Кроки гортаються кнопками «Назад» і «Далі».
- **Перевірити**: результат перевірки з'являється в журналі.
- **Посилання автора**: наведіть мишку на лівий верхній кут і натисніть стрілку. Адреси задаються у `frontend/js/links.js`.
- **Полотно**: колесо миші змінює масштаб, перетягування рухає полотно або блок, `F` вміщує ланцюг, пробіл зупиняє дрейф зв'язків, `Esc` знімає вибір.
- **Висота панелі** змінюється, якщо потягнути ручку в її нижньому краї; подвійний клік повертає автоматичну висоту.

## Будова

```text
src/
  main.rs         HTTP-сервер (tiny_http), файли інтерфейсу, запуск Chromium
  blockchain.rs   Block, Blockchain: майнінг, підробка, перевірка, збереження
frontend/
  index.html      розмітка: полотно, панель керування
  style.css       оформлення, світла і темна теми
  js/main.js      панель керування, дії, журнал
  js/graph.js     полотно Canvas 2D: блоки, хвилясті зв'язки, камера, анімації
  js/explainer.js покрокове пояснення створення блоку
  js/api.js       запити до HTTP API
  js/log.js       журнал подій
  js/drawer.js    бокова панель із посиланнями автора
  js/links.js     адреси посилань автора
```

Бібліотеки: `sha2` (SHA-256), `serde` і `serde_json` (JSON і файл), `tiny_http` (сервер).

### Блок і хеш

```text
hash = SHA-256( index | timestamp | prevHash | difficulty | nonce | data )
```

Для кожного блоку перевіряється:

- `hashOk`: збережений хеш дорівнює перерахованому з поточних даних;
- `linkOk`: `prevHash` дорівнює хешу попереднього блоку;
- `powOk`: хеш починається з `difficulty` нулів.

### HTTP API

Кожна відповідь містить увесь ланцюг і результати перевірки.

| Запит | Дія |
|---|---|
| `GET /api/chain` | поточний стан |
| `POST /api/blocks` (тіло: дані) | замайнити новий блок |
| `POST /api/blocks/{i}/data` (тіло: дані) | підробити дані блоку |
| `POST /api/blocks/{i}/mine?cascade=0\|1` | перемайнити блок або до кінця |
| `POST /api/difficulty?value=n` | змінити складність |
| `POST /api/reset` | повернути початковий ланцюг |
